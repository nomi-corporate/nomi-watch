# Nomi Watch

Repositório reservado para o aplicativo ou integração do Nomi com smartwatches. O alvo inicial é o RM22 com Micro OS 10, cuja capacidade de instalar aplicativos próprios e integrar voz ainda não foi confirmada.

## Estado

Investigação técnica. Nenhum SDK, linguagem ou suporte a instalação está definido. Nenhum aplicativo funcional foi implementado. Apple Watch é uma evolução futura, não uma dependência inicial.

## Limites

Este é um cliente ou adaptador de dispositivo, não um microsserviço. Não acessa diretamente bancos dos serviços. A arquitetura dependerá do suporte do fabricante e do aplicativo acompanhante.
